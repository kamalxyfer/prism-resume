# PRISM Auto AI

Publish `index.html` and `.nojekyll` together to the same GitHub Pages folder. Open the published HTTPS URL for AI. The resume builder and Smart Assist require no account or API key.

Local AI starts automatically at step 6. Select **Use Smart Assist instead** on step 5 to skip the model download. The first Local AI setup uses approximately 415 MB of model, tokenizer and runtime files. A browser may clear cached files. If Local AI cannot start, Smart Assist becomes available immediately. Select **Generative Local AI** to retry.

Use **Print / Save PDF** for the designed layout and **Download DOCX** for an editable text version. Use **Backup JSON** to preserve the editable PRISM design and resume data.
